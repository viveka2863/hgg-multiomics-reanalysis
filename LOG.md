## 2026-10-21 PRE-REGISTRATION: C10 guilt-by-association function prediction (written BEFORE running any C10 script)
Prior knowledge: C4 showed that enrichment depends on the reference set; C8 and C2 part C showed a global tumour-over-cortex group shift in both layers. The controls below target that shift. No C10 quantity was computed before this entry.
Data: universe = the paper's 4,703 DE proteins (analysis/C3_coexpression/original/labels_with_accession.csv, columns Protein_Accession and paper = WP-C1..5), mapped to genes via the GN column of hgg_whole_v1 (drop NA; one row per gene = highest mean abundance); expression = log2 of the rescaled protein matrix (C2 rescale factors), 10 samples; gene sets = JUMPn/JUMPnp/kegg_DB (human symbols mapped with hs_mm_homo_r66, as in C4), restricted to the universe, sets with >= 10 genes. Network weight w_ij = max(Pearson r_ij across the 10 samples, 0), diagonal 0.
Method (leave-one-gene-out neighbour voting): for a set S and a held-out member g, the score of every gene j is the sum of w(j, h) over h in S without g; AUC_g = share of non-members whose score is below g's; set AUC = mean of AUC_g over the members. Null: 1,000 random gene sets of the same size (seed 1), p = (1 + #null >= observed) / (1 + 1000), BH over sets.
- Q-A Main: median set AUC, number of sets with AUC >= 0.7, number significant (BH < 0.05). GBA is "informative" if the median set AUC >= 0.65.
- Q-B Baselines: degree-only score (sum of w over all genes) and cluster vote (share of the other set members in the gene's WP cluster); median set AUC for each and the median gain of GBA over each. GBA "adds value" if the median gain over both is >= 0.05.
- Q-C Group-structure control: network from within-group residuals (subtract each gene's group mean for Cortex, PDGFRA, NTRK, then Pearson across the 10 samples); median set AUC. "Driven by the group structure" if the median AUC falls by >= 0.10 relative to Q-A.
- Q-D Robustness: Spearman network; without TRK3 (9 samples); leave-one-sample-out (10 runs); stable if the median set AUC >= 0.65 in >= 9 of 10 runs.
- Q-E Named sets (descriptive): AUC for KEGG_CELL_CYCLE, KEGG_OXIDATIVE_PHOSPHORYLATION, KEGG_RIBOSOME, KEGG_SPLICEOSOME, KEGG_CITRATE_CYCLE_TCA_CYCLE, KEGG_FOCAL_ADHESION and the nine S_wide sets from C4.
