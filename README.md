# HGG multi-omics re-analysis

How robust are the conclusions of Wang et al. (2019) to the choice of data mining method?
We re-analyse proteome and phosphoproteome data from PDGFRA- vs NTRK1-driven
high-grade glioma, comparing the authors' methods with alternatives.

**Credit:** Wang H. et al., *Nat Commun* 10:3718 (2019), doi:10.1038/s41467-019-11661-4.
Original code (unmodified, in `JUMPn/` and `JUMPp/`): github.com/hongwang198745/HGG_Source_Code.
The authors' README is kept as `README_original.md`.

**Status:** Phase 0, setup.
