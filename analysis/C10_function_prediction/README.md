# C10 guilt-by-association function prediction (design pre-registered in LOG.md, 2026-10-21)

- **Kept:** the paper's use of co-expression to infer function (WP clusters of the 4,703 DE proteins), tested by hiding a gene's KEGG membership and predicting it from its co-expression neighbours (leave-one-gene-out neighbour voting; original/).
- **Compared:** the Pearson network vs a degree-only baseline and a cluster-vote baseline; the main network vs a within-group residual network; Spearman; without TRK3; leave-one-sample-out (improved/).
- **Added:** a random-set null (1,000 sets per size, BH) and named-set AUCs.
- **Result:** universe 4,699 genes (one fusion accession absent, three without symbol), 125 KEGG sets with >= 10 genes. Median set AUC 0.657; 47 sets >= 0.7; 76 significant (BH < 0.05). Baselines: degree 0.548, cluster vote 0.603; paired median gain 0.056 and 0.057. Within-group network 0.677 (+0.020). Spearman 0.660; without TRK3 0.650 (0.649999); leave-one-out 0.650-0.662, >= 0.65 in 9 of 10 runs. Named sets: oxidative phosphorylation 0.926, ribosome 0.945, cell cycle 0.796, focal adhesion 0.406; the nine S_wide sets 0.54-0.73 (KEGG_MTOR has 9 genes: descriptive only).
- **Verdict:** C10a informative (median 0.657 >= 0.65; narrow margin). C10b adds value over both baselines (gain 0.056 / 0.057 >= 0.05; narrow). C10c not driven by the group structure (within-group network 0.677 vs 0.657) and stable (9/10 runs; the TRK3-out run sits at the threshold). The signal is strong for protein complexes and core machinery and weak for signalling sets. Limits: the universe is the 4,703 DE proteins; 10 samples; thresholds close to the observed medians; no external network.
