Verdict: method-dependent (pre-registered rules: Q-B fraction 0.22-0.38 < 0.9; Q-D fails). Refinement (exploratory): tumour vs cortex separation is robust; the PDGFRA-vs-NTRK split rests on TRK1 and TRK2, with TRK3 intermediate. Limits: n = 10; the TRK3 hypothesis arose from the same samples; cause of TRK3's position unexplained (mCherry about half of TRK1/2, fusion-protein row 0.88x, GFP equal); RNA layer not in repo.
