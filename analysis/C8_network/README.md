# C8 kinase-TF network (design pre-registered in LOG.md, 2026-10-20)

- **Kept:** the paper's idea of a kinase -> phosphosite on a TF -> TF target chain with NTRK > PDGFRA > Cortex ordering in every layer, built from the shipped kinase-substrate table, IKAP activities, phospho matrix and TF target lists (original/c8_original.R); transcripts replaced by the proteome.
- **Compared:** rule R0 (3/3 layers ordered) vs V1 (2/3 layers), V2 (without TRK3) and 10 leave-one-sample-out runs (improved/c8_improved.R).
- **Added:** base rates per layer and observed vs expected accepted edges under independence; candidate vs accepted node degrees (Spearman) and betweenness; descriptive status of the 4 CRISPR TFs.
- **Result:** candidate set 28 edges / 15 kinases / 14 TFs (the pre-registered 32/18/14 counted upper- and lower-case kinase names separately); R0 accepts 15 of 28 edges; 7/7 paper nodes and AKT1->BRCA1 S686 accepted; V1 accepts 26 edges (Jaccard 0.58), V2 identical to R0 (1.00), leave-one-out >= 0.8 in 8/10 runs (TRK1 0.75, TRK2 0.67); base rates 0.578 (kinase activity), 0.405 (phosphosite), 0.953 (TF targets; 28/28 candidate edges pass), expected 6.25 vs observed 15 (ratio 2.40, assumes independent layers); degree Spearman 0.55 (29 nodes), 0.80 (15 accepted); MYC (hit) and BRCA1, EP300, JUND (non-hits) all accepted.
- **Verdict:** C8a (explicit rule rebuilds the paper's nodes): recovered (7/7). C8b (robustness): not robust by the pre-registered rule. C8c (informativeness): informative by the registered ratio (2.4 >= 2), but the independence assumption is doubtful (IKAP infers activity from phosphosites; the TF-target layer passes every candidate edge); tested in part B. Limits: transcripts replaced by the proteome; candidate set limited to 28 edges (JUN, CEBPB, PRKCA, PRKAA1 have none); hub status tracks database coverage.
- **Part B (exploratory, pre-registered 2026-10-20):** exact label-permutation null over all 4,200 assignments: median 0 accepted edges (3,461 give 0); observed 15 edges p = 0.0445 (7/7 paper nodes p = 0.0433). Group offsets are Cortex < PDGFRA < NTRK in both layers (proteome -0.136 / 0.043 / 0.079; phospho -0.151 / 0.059 / 0.073). After median-centring each sample, R0 accepts 12 edges (80%) and recovers 7/7 nodes; base rates fall (phosphosite 0.405 -> 0.310; TF targets 0.953 -> 0.467). Circularity: 21 of 28 candidate edges share the site with IKAP's input matrix, 9 of 15 accepted edges; the 6 MYC edges are not circular and all survive centring. Pre-registered interpretation: co-activation beyond global shift. Post hoc: restricted to the 35 assignments that keep the true Cortex group, the observed 15 edges ranks 2nd (p = 2/35 = 0.057). Part B verdict: C8c borderline (0.044 / 0.057); limits: the IKAP layer was not centred, layers are dependent.
